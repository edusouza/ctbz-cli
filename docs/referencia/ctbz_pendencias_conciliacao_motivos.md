# ctbz pendencias conciliacao motivos

Lista os motivos aceitos para justificar uma pendência de conciliação

Lista os motivos (tipoResolucaoPendencia) que ctbz pendencias conciliacao resolver --motivo
aceita, com o rótulo em português e se o motivo exige --socio. "Outro" não existe na API: no
painel, ele abre um atendimento.

## Uso

```
ctbz pendencias conciliacao motivos
```

## Flags globais

```
  -h, --help            mostra a ajuda do comando
  -o, --output string   formato de saída: table, json ou csv (padrão: CTBZ_OUTPUT ou table)
      --verbose count   mostra as requisições no stderr, sem segredos (repita para incluir os corpos; ou CTBZ_DEBUG=1 ou 2)
```
