# ctbz notas entrada produtos

Lista os itens de uma nota de entrada e como estão classificados

Lista os produtos de uma NF-e de compra, com a quantidade total e quanto dela está em
estoque, insumo, uso e consumo, ativo imobilizado e prestação de serviço.

## Uso

```
ctbz notas entrada produtos ID
```

## Exemplos

```sh
  ctbz notas entrada produtos 1000000000000701
```

## Flags globais

```
  -h, --help            mostra a ajuda do comando
  -o, --output string   formato de saída: table, json ou csv (padrão: CTBZ_OUTPUT ou table)
```

Veja também: [`ctbz notas entrada`](ctbz_notas_entrada.md).
