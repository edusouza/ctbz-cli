# ctbz primeiros-passos dispensar

Oculta o card de primeiros passos do painel

Oculta o card de primeiros passos do painel (risco baixo: dispensar e reativar desfazem um ao outro).
Pede confirmação (--yes em scripts) e aceita --dry-run.

## Uso

```
ctbz primeiros-passos dispensar [flags]
```

## Flags

```
      --dry-run   mostra a requisição que seria enviada, sem enviar
  -y, --yes       envia sem pedir confirmação (obrigatório sem terminal)
```

## Flags globais

```
  -h, --help            mostra a ajuda do comando
  -o, --output string   formato de saída: table, json ou csv (padrão: CTBZ_OUTPUT ou table)
```
