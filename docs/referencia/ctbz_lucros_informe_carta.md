# ctbz lucros informe carta

Mostra a carta de responsabilidade do informe de rendimentos de um ano

## Uso

```
ctbz lucros informe carta [flags]
```

## Exemplos

```sh
  ctbz lucros informe carta --ano 2025
```

## Flags

```
      --ano int   ano-calendário (padrão: o ano anterior)
```

## Flags globais

```
  -h, --help            mostra a ajuda do comando
  -o, --output string   formato de saída: table, json ou csv (padrão: CTBZ_OUTPUT ou table)
```
